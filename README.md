# ESP32-C6 LCD → BLE OBD-II

Скетч для **Waveshare ESP32-C6-LCD-1.47** (ST7789 IPS 172×320, SPI): подключается по **BLE** к адаптеру ELM327 и показывает:

- напряжение АКБ
- обороты (RPM)
- температура ОЖ
- скорость, дроссель, нагрузка двигателя (на обзорной странице)

Страницы на экране сами переключаются каждые 4 секунды.

## Железо

| Что | Примечание |
|-----|------------|
| Waveshare ESP32-C6-LCD-1.47 | Цветной ST7789 172×320, SPI |
| BLE OBD-II / ELM327 | Именно **BLE**, не классический BT 2.0 |

Пины дисплея (уже в `config.h`):

| Сигнал | GPIO |
|--------|------|
| MOSI | 6 |
| SCK | 7 |
| CS | 14 |
| DC | 15 |
| RST | 21 |
| BL | 22 |

## Библиотеки (Arduino IDE / Library Manager)

1. **NimBLE-Arduino** (h2zero) — BLE
2. **GFX Library for Arduino** (Arduino_GFX) — дисплей

Плата: **ESP32C6 Dev Module**, опция USB CDC On Boot = Enabled.

## Настройка адаптера

В `config.h`:

```cpp
#define OBD_TARGET_NAME  ""   // пусто = автопоиск по имени (OBD/ELM/Vgate…)
// или точно:
// #define OBD_TARGET_NAME  "OBDII"
// #define OBD_TARGET_NAME  "AA:BB:CC:DD:EE:FF"
```

Скетч пробует три набора BLE UUID (у клонов они разные):

- `FFF0 / FFF1 / FFF2`
- `18F0 / 2AF0 / 2AF1`
- Nordic UART

Если не коннектится — открой **nRF Connect** на телефоне, посмотри Service/Notify/Write UUID адаптера.

## Важно: BLE vs Classic Bluetooth

| Тип адаптера | Работает с этим скетчем? |
|--------------|--------------------------|
| BLE / BLE 4.0 (пишет «iOS», «BLE») | Да |
| Обычный HC-05 / BT 2.0 / «Bluetooth» без BLE | Нет — нужен Classic SPP |

Дешёвые ELM327 v1.5 часто **только Classic**. Для них нужен другой скетч на `BluetoothSerial` (классический ESP32, не S3/C3).

## Запуск

1. Вставь OBD-адаптер в разъём, включи зажигание.
2. Прошей ESP32, открой Serial Monitor **115200**.
3. На экране: Scanning → Connected → данные.
4. В логе будет список BLE-устройств и выбранный UUID-пресет.

## PID’ы

| Параметр | Команда |
|----------|---------|
| Напряжение | `ATRV` (fallback `0142`) |
| RPM | `010C` |
| ОЖ °C | `0105` |
| Скорость | `010D` |
| Дроссель | `0111` |
| Нагрузка | `0104` |

Если какой-то параметр на машине не поддерживается, на экране останется `--`.
